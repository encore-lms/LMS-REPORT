주차별 산출물

1주차 — 09-01(화) ~ 09-04(금)

산출물 — LMS 활동 내역 기반으로 분석된 주간 리포트

출결 · 퀴즈 · 과제 등 LMS에서 발생한 활동 내역을 근거로 분석된 리포트가 수강생 화면에 뜨는 상태입니다. 리포트를 만드는 쪽과 전달 API는 이미 끝나 있고, 이 주에 만드는 것은 그것을 수강생에게 보여주는 화면입니다.

LMS 활동 내역 전달 API LMS 2 LMS 08-18 완료 GOV-AI 측이 전용 키로 호출해 응답을 받아 봅니다
활동 내역 기반 주간 리포트 생성 GOV-AI 3 GOV-AI 08-31 완료 수강생 · 주차를 지정해 리포트 API 응답을 봅니다

2주차 — 09-07(월) ~ 09-11(금)

산출물 — ATmux · PlayLang에서 발생한 데이터와 LMS 활동 내역이 모두 합쳐진 주간 리포트

1주차 리포트에 실습 환경에서 발생한 데이터가 더해진 형태입니다. 두 데이터를 합치는 것은 GOV-AI 측에서 이뤄지고, LMS는 갱신된 응답 구조에 맞춰 화면을 다시 구성합니다. 09-09까지 합쳐진 리포트를 받고, 09-10에 화면 재구성을 끝내고, 09-11에 검증합니다.
