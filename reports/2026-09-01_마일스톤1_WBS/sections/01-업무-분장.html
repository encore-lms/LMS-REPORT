GOV-AI 측 업무

# 업무 주요 작업 산출물
1 DataLake 인프라 구축 · 가동 완료
  • 컨테이너 6종 구동 — LMS 연동 sync · 시계열 DB · RDB · 프론트엔드 · 백엔드 API
  • 수강생 목록 · 상세 화면에서 수집 데이터 확인
 동작 중인 DataLake 서버 datalake.isitsoft.kr
2 LMS 데이터 수집 스케줄러 완료
  • 매일 새벽 5시 LMS 전달 API 호출로 전량 수집
  • 수집분을 수강생 단위로 적재 — 화면의 출결 · 퀴즈 · 과제가 이 경로로 들어옴
 주기 동기화가 도는 LMS 연동
3 주간 AI 리포트 생성 · 제공 완료
  • 주차 스냅샷이 있으면 즉시 반환, 없으면 LLM 호출 — 약 10초
  • 주간에 쌓인 스냅샷과 ATmux · PlayLang 실습 데이터를 근거로 등급 · 이탈 위험도 판정 실습 데이터는 현재 시뮬레이터 생성분
  • 마크다운 · JSON 두 형식으로 출력
  • 정기 배치 생성은 후속 — 현재는 조회 시 생성
 주간 리포트 조회 API
4 ATmux · PlayLang 구현 완료
  • ATmux — 사용량 메트릭 발생
  • PlayLang — 코스 · 단계 · 사용 언어 · 에러 · 실행 이벤트 발생
 실습 환경 자체가 동작하는 상태 수집 연동 테스트는 업무 5
5 ATmux · PlayLang 시뮬레이터 검증 진행 중
  • 학생별 시뮬레이터로 실습 데이터를 생성해 전 구간 검증
  • 출결 · 퀴즈 · 과제 성취도가 높을수록 진도가 잘 나가도록 맞춰 생성
  • 남은 것 — 학생별 실 메트릭 수집 테스트
 시뮬레이션 데이터로 한 바퀴 도는 것이 확인된 상태
6 실습 데이터 · LMS 데이터를 합친 주간 리포트 생성 진행 예정
  • ATmux · PlayLang 실연동이 끝나면 실 실습 데이터와 LMS 전달 데이터를 합쳐 주간 리포트를 생성
  • 시뮬레이터 데이터를 실 데이터로 교체
 실 데이터 기반 주간 리포트
7 정량 리포트 · 이탈 부진 분석 완료

  • 과정 전체 수강생 대상 이탈 · 부진 분석 — 약 10~15초
 분석 결과 조회 API
8 강사 피드백 초안 · 검토 발송 완료
